# BTP paper collection

Working title: **Trustworthy AI-Assisted Coral-Reef Health Assessment** (Lakshadweep temporal-change detection deferred to a later phase).

## Core papers in use (this folder)

- **Coralscapes / reef segmentation** — Sauder et al. 2025 (dataset paper; see project/research-sources.md link)
- [Monitoring_of_Coral_Reefs_Using_Artificial_Intelli.pdf](Monitoring_of_Coral_Reefs_Using_Artificial_Intelli.pdf) — González-Rivero et al. 2020, main methodological precedent
- [s41598-025-20795-z.pdf](s41598-025-20795-z.pdf) — Sauder et al. 2025, DeepReefMap (frame sampling/aggregation ideas)
- [1-s2.0-S157495412500216X-main.pdf](1-s2.0-S157495412500216X-main.pdf) — Wyatt et al. 2025, OOD detection benchmark
- [1-s2.0-S1574954126002372-main.pdf](1-s2.0-S1574954126002372-main.pdf) — Wyatt et al. 2026, uncertainty-aware monitoring
- [Dey_2025_Lakshadweep_Coral_Composition.pdf](Dey_2025_Lakshadweep_Coral_Composition.pdf) — Lakshadweep ecological context
- [Guo_2017_On_Calibration_of_Modern_Neural_Networks.pdf](Guo_2017_On_Calibration_of_Modern_Neural_Networks.pdf) — calibration baseline for the trust layer
- [Hendrycks_Gimpel_2017_OOD_Baseline.pdf](Hendrycks_Gimpel_2017_OOD_Baseline.pdf) — max-softmax OOD baseline for the trust layer
