## Current project

**Trustworthy AI-Assisted Coral Reef Health Assessment**

This phase focuses on broad visible benthic and coral-condition indicators from underwater imagery, with explicit quality and reliability warnings. Temporal change detection and Lakshadweep-specific validation are outside the current implementation scope.
