# Coral-Reef Dataset Inventory

**Inventory checked:** 2026-10-05  
**Project:** Trustworthy AI-Assisted Coral Reef Health Assessment

This file records datasets found in the workspace and the external sources supplied for the project. “Local status” describes files currently present under `/mnt/Work/BTP`; it does not mean the dataset is complete, licensed for every use, or ready for training. Dataset facts below are taken from the linked dataset/provider records or the downloaded metadata. Verify the current license, version, and access conditions before using or redistributing any data.

## Underwater imagery and annotations

| Dataset | What it contains | Local status | Source and access notes |
|---|---|---|---|
| **Coralscapes** | 2,075 Red Sea reef images from 35 dive sites in five countries, with dense semantic segmentation masks and 39 benthic classes (about 174,000 polygons). Includes live, bleached, and dead coral classes as well as algae, sand, rubble, fish, and other scene classes. | **Present.** `datasets/coralscapes.7z` and an extracted image/mask tree are present. The workspace has 4,152 files under `datasets/coralscapes/`. | [Zenodo record 15061505](https://zenodo.org/records/15061505) · [Hugging Face dataset](https://huggingface.co/datasets/EPFL-ECEO/coralscapes). These are two access records for the same Coralscapes corpus, not separate datasets. The Hugging Face card lists Apache-2.0; the Zenodo record does not show a populated license field. Verify which terms cover the specific files before redistribution. Images are from the Red Sea, so this is not Lakshadweep ground truth. |
| **Moorea Labeled Corals (MCR LTER package knb-lter-mcr.5006.3)** | 2,055 Moorea underwater survey images from 2008–2010 and nearly 400,000 random-point annotations. The nine most common labels include CCA, turf algae, macroalgae, sand, and five coral genera: *Acropora*, *Pavona*, *Montipora*, *Pocillopora*, and *Porites*. These are point labels, not dense masks. | **Archives present.** Package metadata and year ZIP archives are under `datasets/archive/knb-lter-mcr.5006.3/`; image contents have not been extracted into a working image tree. | [MCR LTER dataset page](https://mcr.lternet.edu/data/datasets/mcr-lter-coral-reef-computer-vision-moorea-labeled-corals) · [MCR LTER data portal and data-use policy](https://mcr.lternet.edu/data). The MCR portal says use of public data requires acceptance of the MCR-LTER Data Use Policy; follow the linked package terms. |
| **ReefNet-1.0, including the Red Sea Global test subset** | A global collection of CoralNet point annotations with original CoralNet labels, harmonized ReefNet labels, image/source IDs, coordinates, broad categories, and geographic metadata. The RSG test subset is from the Al-Wajh lagoon in the Red Sea. Annotations are points, not segmentation masks. | **Partial metadata only.** Local files include RSG annotations, label mappings, source metadata, image-download metadata, and a Croissant metadata JSON under `retrieved_materials/datasets/reefnet_rsg/`. The associated image archive is **not present**. | [Hugging Face dataset card and files](https://huggingface.co/datasets/ReefNet/ReefNet-1.0) · [ReefNet project page](https://reefnet-project.github.io/reefnet-2025/). The card lists CC BY-NC-SA 4.0. The Hugging Face viewer currently reports a schema/conversion error for mixed condition values; use the raw files and inspect their schema. Do not use image-level or point-level rows as independent splits when they share source images or sites. |
| **NOAA PIFSC Coral Bleaching Classifier imagery and annotations** | Hawaiian Archipelago photoquadrat imagery collected during research missions from 2014–2019. Package includes image metadata, human training point annotations, human/machine test annotations, a label set, and imagery; labels support coral-bleaching classification. | **Metadata/reference pages only.** Saved NOAA InPort and CoralNet HTML records are under `retrieved_materials/datasets/noaa_bleaching/`; imagery and annotation exports are not present locally. | [NOAA InPort record 67962](https://www.fisheries.noaa.gov/inport/item/67962) · [NOAA NCEI accession 0269246](https://www.ncei.noaa.gov/archive/accession/0269246) · [NOAA CoralNet source 2947](https://coralnet.ucsd.edu/source/2947/). This is Pacific/Hawaiian condition data, not Lakshadweep validation data. The record lists no access constraints and asks users to cite NOAA Fisheries ESD; check each imagery file's ownership/use terms before reuse. |
| **Coral Reef Dataset (Kaggle, jxwleong)** | A curated image collection described as drawing from CoralNet and MCR LTER, with `combined_annotations_remapped.csv`; the uploader describes it as intended for coral-image classification and localization. Exact remapped classes and geographic composition were not established from the dataset metadata. | **Not found locally.** | [Kaggle dataset page](https://www.kaggle.com/datasets/jxwleong/coral-reef-dataset) · [Kaggle metadata API](https://www.kaggle.com/api/v1/datasets/view/jxwleong/coral-reef-dataset). Metadata reports about 19.8 GB total and license `Unknown`. Inspect the annotation CSV, provenance, and rights before using; do not assume compatibility with the project labels. |
| **MERMAID Community Coral Reef Image Classification Training Data** | Community-sourced, continually updated reef-image classification training data with confirmed annotations contributed through MERMAID and partners; the S3 bucket may contain data from multiple sources and structures. | **Not found locally.** | [AWS Open Data Registry page](https://registry.opendata.aws/coralreef-image-classification-training/) · [MERMAID open-data documentation](https://github.com/data-mermaid/image-classification-open-data). Registry lists CC BY-NC-SA 4.0 for the collection. Audit source-specific labels and metadata before combining rows; this is a changing collection, so record the exact snapshot/date used. |
| **DeepReefMap example data** | Example GoPro Hero 10 MP4 videos from Red Sea reefs plus semantic-segmentation and structure-from-motion model checkpoints. The record describes demonstration/reconstruction data; it does not describe a labelled mask training set. | **Not found locally.** | [Zenodo record 10624794](https://zenodo.org/records/10624794) · [DeepReefMap code and instructions](https://github.com/josauder/mee-deepreefmap). Zenodo lists a 10.3 GB example archive and a README; the license field is not populated on the record. Useful for a video-processing demo, not a substitute for labelled training data. |

## Lakshadweep ecological and environmental context

| Dataset | What it contains | Local status | Source and access notes |
|---|---|---|---|
| **Lakshadweep coral-composition observations (Dryad)** | Three CSV tables for Agatti, Kadmat, and Kavaratti with photoquadrat-derived coral cover/composition, genus and lifeform, year, atoll/site, aspect, depth/depth class, transect, quadrat, and percentage cover. Observations span 1998–2022. These are ecological measurements, not an image-training corpus. | **Present.** CSVs and README are under `datasets/archive/doi_10_5061_dryad/`; a source ZIP is also present under `datasets/`. | [Dryad dataset DOI 10.5061/dryad.vq83bk3z5](https://datadryad.org/dataset/doi:10.5061/dryad.vq83bk3z5). Use for Lakshadweep ecological context and comparison targets, not as image labels. |
| **Lakshadweep long-term coral occurrence records (GBIF / NCF)** | Darwin Core occurrence records for coral genera from photoquadrat monitoring at three atolls during 2001–2022, with site, depth, exposure, date, taxon, and related occurrence fields. The accompanying metadata declares CC BY 4.0. | **Present.** Extracted Darwin Core files and source ZIP are under `datasets/archive/dwca-ncf-ocp-coral-longterm-v1.0/`. | [GBIF dataset page](https://www.gbif.org/dataset/36fbf9a0-1c96-4080-8bba-06b89f444257) · [NCF/GBIF resource record](https://cloud.gbif.org/asia/resource?r=ncf-ocp-coral-longterm&v=1.0). This is occurrence/context data, not labelled imagery. |
| **Lakshadweep reef-fish occurrence records (GBIF)** | A GBIF occurrence download of 4,761 records from underwater visual census surveys at Agatti, Kadmat, and Kavaratti, covering 2011–2026 and shallow/deep strata. Fish records are not coral-condition labels. | **Present.** Darwin Core files and the download archive are under `datasets/archive/0046566-260806074905277/` and `datasets/`. | [GBIF DOI 10.15468/6nz4x9](https://doi.org/10.15468/6nz4x9). Local metadata declares CC BY 4.0. Useful as regional ecological context only. |
| **NOAA Coral Reef Watch Lakshadweep heat-stress series** | Daily satellite-derived thermal-stress fields in the local CSV, including SST, HotSpot/DHW-related fields, and bleaching-area indicators. This is environmental context, not an observed coral-condition label. | **Present.** `datasets/archive/NOAA_Lakshadweep_RVS_Thermal_PRESERVED_DATE.csv`. | [NOAA Coral Reef Watch Lakshadweep regional products](https://coralreefwatch.noaa.gov/product/vs/gauges/lakshadweep.php). Preserve the source date and product/version when analyzing the local snapshot. |

## Inventory notes

- The main dense-mask dataset is Coralscapes; the main point-annotation datasets are Moorea Labeled Corals and ReefNet.
- The supplied Coralscapes Hugging Face and Zenodo URLs refer to the same underlying dataset and are recorded in one row.
- The local ReefNet material does not include the RSG image archive. Local NOAA bleaching material is metadata only. Kaggle and DeepReefMap example data are not present locally.
- Dryad, GBIF, and NOAA thermal data provide ecological or environmental context. They are not substitutes for labelled image data.
- Before model training, record exact revisions, checksums, licenses/access terms, original labels, and any project label mapping in the dataset manifest.
