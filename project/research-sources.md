# Verified Sources

Updated 2026-10-05 for the general coral-reef health-assessment scope.

- Coralscapes dataset: 2,075 underwater images from 35 dive sites in five countries, 39 benthic classes and roughly 174k polygons. https://huggingface.co/datasets/EPFL-ECEO/coralscapes
- Coralscapes paper: https://openaccess.thecvf.com/content/ICCV2025W/CVAUI%20%26%20AAMVEM/papers/Sauder_The_Coralscapes_Dataset_Semantic_Scene_Understanding_in_Coral_Reefs_ICCVW_2025_paper.pdf
- NOAA PIFSC coral-bleaching dataset card: https://huggingface.co/datasets/NMFS-OSI/NOAA-PIFSC-ESD-CORAL-Bleaching-Dataset
- CoralNet: https://coralnet.ucsd.edu/
- ReefNet: https://reefnet-project.github.io/reefnet-2025/
- MERMAID community image-training data: https://registry.opendata.aws/coralreef-image-classification-training/
- YOLO26 documentation: https://docs.ultralytics.com/models/yolo26/
- YOLO26 semantic-segmentation data format: https://docs.ultralytics.com/tasks/semantic/
- Ultralytics system requirements: https://docs.ultralytics.com/help/FAQ/
- Calibration foundation - Guo et al. (2017): https://arxiv.org/abs/1706.04599
- OOD/misclassification baseline - Hendrycks and Gimpel (2017): https://arxiv.org/abs/1610.02136

## Source-handling note

Record exact data versions, licences, access dates, checksums, original labels and the published label map before any training. Public datasets provide benchmarks, not a blanket claim of health-assessment validity across all reefs.
