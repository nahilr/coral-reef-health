# Coral-Reef Dataset Inventory

**Inventory checked:** 2026-10-19
**Project:** Trustworthy AI-Assisted Coral Reef Health Assessment

This file records datasets found in the workspace and the external sources supplied for the project. “Local status” describes files currently present under `/mnt/Work/BTP`; it does not mean the dataset is complete, licensed for every use, or ready for training. Dataset facts below are taken from the linked dataset/provider records or the downloaded metadata. Verify the current license, version, and access conditions before using or redistributing any data.

Observations span 1998–2022. These are ecological measurements, not an image-training corpus. | **Not found under `data/raw/` in this review.** The previously documented `datasets/archive/doi_10_5061_dryad/` path and source ZIP are absent. | [Dryad dataset DOI 10.5061/dryad.vq83bk3z5](https://datadryad.org/dataset/doi:10.5061/dryad.vq83bk3z5). ## Inventory notes

The current `data/raw/` directory contains Coralscapes, a partial extracted MCR package and its ZIP, DeepReefMap example videos/checkpoints, and two undocumented MP4 clips. CoralscapesV2 is intentionally not stored locally; its Kaggle workflow streams the data there. The current directory's total reported size is about 19 GiB. There is no `datasets/archive/` directory in this review; the Dryad, GBIF, and NOAA CSV paths previously listed there are therefore stale. Counts above describe the files actually present, not an integrity check or confirmation that every file can be decoded.

## Dataset roles and use plan

| Priority/role | Dataset | Planned use | Constraint |
|---|---|---|---|
| Primary segmentation | CoralscapesV2 | Kaggle streams the official splits, trains the project-taxonomy (7-class) model, and saves pixel accuracy and per-class/macro IoU for the official test split. Retain raw 95-class labels and document the explicit 95-to-7 map in `configs/label_map.json`. | V2 labels are visual annotations, not a complete ecological health measure. Health ratios use reef classes only; the `non_reef` discard sink is excluded and reported separately. |
| Historical baseline | Coralscapes V1 | Legacy V1 workflow and checkpoint were removed during consolidation; use the CoralscapesV2 five-backend report for the current benchmark. | Historical V1 scores are not part of the maintained benchmark and are not directly comparable to V2 project-taxonomy metrics. |
| External robustness | One compatible CoralNet, ReefNet, or MERMAID source | Sealed evaluation across a different source/site after label mapping and licensing review. | Point annotations are not dense masks; keep images/sites grouped and avoid mixing incompatible taxonomies. |
| Historical regional context | Agatti, Kadmat, and Kavaratti ecological records | Interpret local cover/composition trends and plan future validation. | Not consumed by the current model pipeline; ecological observations are not image segmentation labels. |
| Demonstration | Separate underwater images/video | Qualitative demo and reviewer assessment. | Keep separate from training, validation, and threshold selection. |

For any added training data, maintain a source/image/site-grouped split manifest, original labels, a written remapping policy, image IDs, source and date metadata, license/access terms, and checksums. Keep ambiguous labels explicit instead of silently relabeling them. Dataset selection is conditional on access, licensing, labels, and actual compatibility; the table is a plan, not a claim that all listed data are currently present or integrated.

- CoralscapesV2 is the primary dense-mask dataset for the consolidated model workflow. The earlier Coralscapes V1 checkpoint and workflow were removed. Moorea Labeled Corals and ReefNet are catalogued as other point-annotation datasets, not current model inputs.
- The supplied Coralscapes Hugging Face and Zenodo URLs refer to the same underlying dataset and are recorded in one row.
- ReefNet files and NOAA bleaching metadata are not present at the previously documented local paths in this workspace review. Kaggle is not present locally. DeepReefMap example videos/checkpoints are present but are demonstration inputs, not a labelled training set.
- The Dryad, GBIF, and NOAA thermal records could provide ecological or environmental context if reacquired; they are not present under `data/raw/` now and would not substitute for labelled image data.
- Before model training, record exact revisions, checksums, licenses/access terms, original labels, and any project label mapping in the dataset manifest.
