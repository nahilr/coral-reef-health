# Paper fit review based on the PDFs

> Archived after consolidation. The authoritative paper review is in [paper-inventory.md](../paper-inventory.md).

Reviewed the 19 PDFs physically present under `papers/` and its subfolders on 2026-10-18. Selection below is based on the paper content and the current implementation in `main.py`, `src/inference/pipeline.py`, `src/evaluate/segmentation.py`, and `src/trust/reliability.py`; the existing inventories and selection notes were not used to choose or rank papers.

## What the current implementation is

The running system predicts seven broad benthic classes from images with YOLO26n-seg, derives composition/reef-condition indicators, applies image-quality and confidence-based review flags, and can repeat this process on sampled video frames. It has a crop-level ResNet18 condition classifier. It currently does not perform repeat-survey change detection, 3D reconstruction, metric transect mapping, cross-region validation, OOD benchmarking, or calibrated uncertainty propagation into cover estimates.

The recorded evaluation is mIoU 0.4038 on 392 test images; per-class IoUs include live coral 0.5181, bleached coral 0.2427, and dead coral 0.1269. Validation mask mAP50 is 0.1652. The ResNet18 crop classifier records 0.3822 accuracy and 0.2264 macro F1 on 382 validation crops. Its ECE report, 0.375, is detection-level and must not be treated as a pixelwise score or OOD score.

## Best-fit papers

| Rank | Paper and local PDF | Fit to the current system | Reported evaluation and comparison limits |
|---:|---|---|---|
| 1 | Sauder et al., *The Coralscapes Dataset: Semantic Scene Understanding in Coral Reefs* ([PDF](../../papers/2503.20000v2.pdf)) | Closest technical benchmark for dense broad-benthic segmentation; it is also the data source used here. | 2,075 images, 39 classes, spatial site split 1,517/166/392. Reported best mIoU is 57.800 and pixel accuracy 82.761 for SegFormer-MiT-b5 with stronger augmentations. Current mIoU 40.38% is the nearest named metric, but not an apples-to-apples comparison: this project merges labels to seven, uses YOLO instance masks rasterized into a class map, and applies its own ignored/unsegmented-pixel handling. |
| 2 | Sauder et al., *Rapid consistent reef surveys with DeepReefMap* ([PDF](../../papers/s41598-025-20795-z.pdf)) | Closest whole-workflow reference: video transects → semantic segmentation → mapped benthic cover → repeatability analysis. | Evaluates 365 transect video replicates across 45 sites and reports 2.51% mean per-site/per-time SD in live coral cover. That repeatability measure is not comparable with this project's mIoU. Current video processing only samples frames and averages reports; it has no 3D mapping, metric transect normalization, or replicate-based repeatability evaluation. |
| 3 | Zheng et al., *CoralVOS: Dataset and Benchmark for Dense Coral Video Segmentation* (2025 version, [PDF](../../papers/archive/additional/CoralVOS_2025_Dense_Coral_Video_Segmentation.pdf)) | Closest video-segmentation reference. It addresses dense coral masks through continuous video, while this implementation predicts masks independently on sampled frames. | 150 videos, 60,456 annotated frames, 17 sites. Table 3 reports J&F scores around 71–78 across methods/settings (e.g. STCN 77.96). J&F evaluates video object segmentation, not seven-class benthic mIoU; the paper is coral-object focused rather than full benthic composition. The 2023 PDF is an earlier version of this work, not an independent benchmark. |
| 4 | González-Rivero et al., *Monitoring of Coral Reefs Using Artificial Intelligence* ([PDF](../../papers/Monitoring_of_Coral_Reefs_Using_Artificial_Intelli.pdf)) | Strongest ecological-metric precedent: model annotations are aggregated into benthic abundance/cover and compared with expert observations. | Reports 97% unbiased agreement, 4% overall error, and 83–94% community-composition agreement across bioregions. These are not pixel mIoU scores. The current project has not measured expert-referenced cover error, agreement, repeatability, or processing-time savings. |
| 5 | Wyatt et al., *Beyond classification accuracy: Uncertainty-aware deep learning for coral reef monitoring* ([PDF](../../papers/1-s2.0-S1574954126002372-main.pdf)) | Best fit for the project's cover indicators and uncertainty goal. It propagates calibrated class probabilities into cover estimates. | Uses calibrated probabilities and Monte Carlo sampling; reports −1.83 to +2.16 percentage-point errors for its MCCC approach in a set of class/dataset comparisons, while balanced training can exceed 20% error in some cases. Those abundance errors are not comparable with current mIoU, crop accuracy, or ECE. The project currently uses deterministic counts and entropy over detection scores, without calibrated Monte Carlo cover intervals. |
| 6 | Wyatt et al., *Safe AI for coral reefs: Benchmarking out-of-distribution detection algorithms* ([PDF](../../papers/1-s2.0-S157495412500216X-main.pdf)) | Best fit for the reliability/review-gate component. It tests whether a model can identify unfamiliar survey data. | Reports OOD metrics AUROC, FPR@95%TPR and survey-level histogram intersection. In far-dataset comparisons, KNN distance reports HI 0.37±0.15, AUROC 0.89±0.07, FPR95 0.37±0.22, and is strongest overall; ViM is generally next. These are OOD detection results, not comparable to current ECE. The implementation's quality/confidence gate has no OOD train/test geography or AUROC/FPR evaluation. |
| 7 | Kopecky et al., *Quantifying the Loss of Coral from a Bleaching Event Using Underwater Photogrammetry and AI-Assisted Image Segmentation* ([PDF](../../papers/archive/remotesensing-15-04077-v2.pdf)) | Strong health/bleaching validation reference: segmentation is connected to measured live/dead coral area before and after a disturbance. | In a five-plot Moorea study, live coral pixels were classified at 93% accuracy and dead coral at 70%; estimated 3D live area changed from 26.7±2.4 to 12.5±1.0 m² and dead area from 1.9±0.3 to 16.6±1.6 m². It uses photogrammetry and human correction, so it is not a direct model benchmark for the current RGB pipeline. |
| 8 | Shao et al. (2025), *Multi-label classification for multi-temporal, multi-spatial coral reef condition monitoring using vision foundation model with adapter learning* ([PDF](../../papers/archive/2503.23012v1.pdf)) | Closest fit for the optional crop-level coral-condition classifier and cross-condition testing. | DINOv2-LoRA tests eight condition/stressor labels across Koh Tao sites/seasons; reported macro F1 includes 60.52% in a cross-season evaluation and 69.42% in held-out habitat evaluation. These multi-label scores are not directly comparable with the current single-label crop-classifier macro F1 of 22.64%; labels, tasks, and evaluation protocols differ. |

## Recommended paper set for the current BTP

Use **Coralscapes** as the segmentation benchmark/data paper, **DeepReefMap** as the video-to-cover workflow and repeatability reference, **González-Rivero** as the ecological abundance/agreement reference, **CoralVOS 2025** as the dense-video segmentation reference, and **Kopecky** as the health/bleaching outcome reference. Use **Wyatt Safe AI** and **Wyatt uncertainty-aware monitoring** as two separate references for OOD review and cover uncertainty. Keep **Shao 2025** as a targeted reference for the optional condition-classifier branch. Dey is the ecological target-context reference, especially if the project scope returns to Lakshadweep-specific evaluation.

The implementation is closest to the field in the broad workflow idea, but not yet in evaluation depth. It needs locally relevant holdouts, expert-referenced cover error, repeated-video consistency, cross-domain/OOD tests, and uncertainty intervals before its health indicators can be compared at the same level as these monitoring studies.
